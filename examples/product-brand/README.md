# Product brand reference

Invented product facts and brand rules → structured encyclopedia → product/type discovery → explicit ID and BrandRule selection → BrandCompiler → copy brief → replaceable text model → reviewed campaign state.

The same engine runs both examples. The entity types and constraints differ; required type tags alter deterministic selection; BrandCompiler adds the tone requirement; BrandOutput emits a copy brief. No model copy or certifications are fabricated. A real project would validate wording and persist approved campaign decisions.
