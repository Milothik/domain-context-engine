Domain Context Engine v2 turns the original reference skeleton into a more usable execution core while keeping provider-independent contracts.

Changes:

- State updates merge fields and nested patches, retain field provenance and validate atomically.
- Ranked multi-hop discovery supports typed relationships, material effects, paths and candidate limits.
- Deterministic selection now includes consequential graph context. A configurable HTTP LLM decision provider includes timeouts, request/response budgets, scoped state and strict reply validation.
- Core schema validation and invariant checks apply even with custom project/compiler adapters.
- The compiler filters unapproved claims, records constraint origins/priorities, detects opposite exact predicates and prunes only optional context with an audit trail.
- Independent gold fixtures span comic, brand and game domains. Four-arm diagnostics and an opt-in live evaluator replace the circular benchmark expectations.
- StateCommitError preserves a validated output after a continuity commit failure.

Validation: 41 automated tests, local HTTP integration, independent-gold mutation checks, offline benchmark and package dry run. GitHub Actions validates this release. No paid/remote LLM quality result is claimed; the integration tests use a local fixture server.

Read `docs/migration-v2.md` for changed defaults. Package version is 0.2.0; default Task Context version is 2.0. Legacy string entity links and v1 context validation remain supported. Memory storage, domain semantic conflict checks and model-specific token budgeting still require deployment/domain adapters.
